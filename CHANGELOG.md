# Changelog

All notable changes to Skills Manager are documented here. The project uses [Semantic Versioning](https://semver.org/) and change-driven releases rather than a fixed calendar.

## [Unreleased]

### Added

- Open-source release policies and clean-checkout compatibility gates.

## [0.1.0] - Unreleased

Initial Public Preview release.

The Skill workflow, Intent document format, and helper output may evolve during 0.x. Breaking preview changes must be identified in this changelog and in GitHub release notes. A change affecting existing Intent documents must include migration instructions and must never silently discard or semantically rewrite an Intent. Urgent security fixes may be released immediately; releases are otherwise made only for meaningful changes.
