# Support

Skills Manager support is best effort. There is no response-time or resolution SLA, and the project does not promise commercial support, private debugging, or environment management.

- Search existing GitHub Issues, then use the question link in the issue chooser for ordinary usage help.
- Use the bug form for reproducible Skills Manager behavior.
- Discuss major features or behavior changes in a feature request before implementation.
- Report vulnerabilities privately through [Security](SECURITY.md), never as an ordinary issue.
- Report discovery, installation, Update, removal, security-prompt, telemetry, or package metadata defects owned by `npx skills` to the [upstream skills project](https://github.com/vercel-labs/skills/issues).

GitHub through `npx skills` is the only supported distribution channel. npm package installation is unsupported.
