# Skills Manager v0.1.0 — Public Preview

Skills Manager v0.1.0 is the initial Public Preview of an Agent-facing workflow built on the public `npx skills` interface. It adds need-aware Skill selection, scope-specific Markdown Intent documents, semantic Intent application during Update, managed removal guidance, and a read-only Customization-patch helper.

## Compatibility

- Node.js 22 and 24 (`>=22`)
- `npx skills >=1.5.19 <2.0.0`
- GitHub installation through `npx skills`; no npm package distribution

## Preview status

This is the initial public release. The workflow, Intent document format, and helper output may change during Public Preview.

## Security and privacy

Customization patches are raw and are not automatically redacted. Review terminal output, Agent conversations, model context, issues, and shared logs before exposing them. See the [security policy](../../SECURITY.md) for private vulnerability reporting.

Before publication, the exact tag target must pass both compatibility endpoint smokes, deterministic Node 22/24 checks, the secret scan, and the isolated Agent workflow certification. Publishing the tag and changing repository visibility remain manual maintainer actions.
