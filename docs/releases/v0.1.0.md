# Skills Manager v0.1.0 — Public Preview

Skills Manager v0.1.0 is the initial Public Preview of an Agent-facing workflow built on the public `npx skills` interface. It adds need-aware Skill selection, scope-specific Markdown Intent documents, semantic Intent application during Update, managed removal guidance, and an attempt-local Intent-application helper.

## Managed workflow

- Every Update runs Update preflight before direct upstream mutation. An Installation with no active Intent completes immediately after upstream success; an upstream failure, timeout, or interruption becomes an Unknown mutation outcome and recovery starts with a new preflight.
- An Installation with active Intents captures an Intent application baseline after upstream success. Its Baseline handle supports repeatable bounded review, Intent application patch generation, conversational Intent application evidence, and explicit closure after completion, Conflict, or cancellation.
- A no-change review classifies each already-satisfied active outcome as a Baseline-satisfied Intent and retains it. Clean upstream acquisition occurs only when proposing an Upstream-fulfilled Intent, and removal still requires user confirmation.
- Direct Intent addition or editing records the approved outcome before installed content changes. Intent removal removes and reviews applied behavior before committing the Intent document change last.
- Batch Update shares preflight reads by scope, baseline capture by scope, and optional clean acquisition by normalized source while retaining independent handles and per-Installation results.
- A Skills Manager self-Update with active Intents is rejected before mutation. The ordinary no-Intent self-Update requires a new Agent session after success.

## Compatibility

- Node.js 22 and 24 (`>=22`)
- `npx skills >=1.5.19 <2.0.0`
- GitHub installation through `npx skills`; no npm package distribution

## Preview status

This is the initial public release. The workflow, Intent document format, and helper output may change during Public Preview.

## Security and privacy

Intent application patches are raw and are not automatically redacted. Review terminal output, Agent conversations, model context, issues, and shared logs before exposing them. See the [security policy](../../SECURITY.md) for private vulnerability reporting.

Before publication, the exact tag target must pass both compatibility endpoint smokes, deterministic Node 22/24 checks, the secret scan, and the isolated Agent workflow certification. Publishing the tag and changing repository visibility remain manual maintainer actions.
